# 🏋️ PlanejaFit

> Plataforma para captação e gestão de leads interessados em planos de treino personalizados.

---

# 📖 Sobre o Projeto

O PlanejaFit é um MVP (Minimum Viable Product) desenvolvido para validar a hipótese de mercado de que usuários estão dispostos a preencher um formulário personalizado e continuar uma negociação via WhatsApp para adquirir um plano de treino adaptado aos seus objetivos.

A solução foi criada seguindo o conceito de validação enxuta, focando apenas nas funcionalidades essenciais para testar a aceitação do negócio antes de realizar investimentos mais complexos.

---

# 🎯 Problema

Muitas pessoas desejam melhorar a saúde, perder peso ou ganhar massa muscular, porém enfrentam dificuldades para:

- Escolher um treino adequado
- Definir objetivos realistas
- Encontrar orientação personalizada
- Contratar um personal trainer presencial devido ao custo

---

# 💡 Solução

O PlanejaFit oferece uma experiência simples:

1. O usuário acessa uma Landing Page
2. Preenche um formulário
3. O sistema registra o lead
4. O usuário é direcionado para o WhatsApp
5. O especialista realiza o atendimento
6. O plano personalizado é vendido e entregue
